# PPDF — Пакетный экспорт в PDF + Объединение для AutoCAD

**PPDF** — это мощное приложение на AutoLISP для AutoCAD (2014 и новее), предназначенное для пакетной печати блоков-рамок в отдельные PDF-файлы с возможностью их автоматического объединения в один документ.

## 🙏 Благодарности

Проект PPDF развивался благодаря идеям и архитектурным решениям из следующих открытых проектов:

- **[LXPDF](https://github.com/Lynxy039/LXPDF)** (автор: [Lynxy039](https://github.com/Lynxy039))  
  *Откуда взяты идеи:* концепция пакетного экспорта рамок непосредственно из пространства Модели, логика умной сортировки листов (по строкам/столбцам) и алгоритм выбора блоков внутри замкнутой полилинии.

- **[autocad-batch-plot (BPDF)](https://github.com/beastt1992/autocad-batch-plot)** (автор: [beastt1992](https://github.com/beastt1992), лицензия: MIT)  
  *Откуда взяты идеи:* структура диалогового интерфейса (DCL), автоматическое определение имени блока-рамки по клику мыши и удобная система сохранения пользовательских настроек между сессиями.

Огромное спасибо авторам за их открытый код и вклад в сообщество пользователей AutoCAD! 🚀

## 🚀 Возможности
* **4 режима выбора рамок:**
  1. **Выборочная** — ручной клик по блокам (с возможностью отмены последнего).
  2. **Все блоки** — печать всех экземпляров указанного блока-рамки.
  3. **Одна рамка** — печать только одного выбранного блока.
  4. **ЗамкПолилиния** — печать блоков, попавших внутрь указанной замкнутой LWPOLYLINE.
* **Умная сортировка:** нумерация листов по строкам (слева направо, сверху вниз) или по столбцам.
* **Автоматическая нумерация:** продолжает последовательность, если в папке уже есть PDF (формат `префикс_суффикс_NNN.pdf`).
* **Объединение PDF:** автоматическое слияние листов в один файл (`префикс_суффикс_merged.pdf`) с помощью `pdftk.exe`.
* **Предполётная проверка:** предупреждение, если в целевой папке уже есть PDF-файлы (с вариантами очистки или архивации).
* **Двуязычный интерфейс (RU / EN):** переключение языка кнопкой «LNG», выбор сохраняется в настройках.
* **Сохранение настроек:** все параметры сохраняются в `%APPDATA%\PPDF\ppdf_settings.cfg`.

## 📦 Требования
1. **AutoCAD** версии 2014 или новее.
2. **pdftk.exe** — только для функции объединения PDF (уже входит в архив релиза вместе с `libiconv2.dll`).
   * Если нужен отдельно: [pdftk Server](https://www.pdflabs.com/tools/pdftk-server/) или [pdftk-java](https://gitlab.com/pdftk-java/pdftk).
   * Файлы `pdftk.exe` и `libiconv2.dll` должны лежать рядом со скриптом, в папке поддержки AutoCAD (например, `C:\Program Files\Autodesk\AutoCAD 20XX\Support\`) или в любой папке из Support File Search Path.

## ⚙️ Установка
1. Скачайте архив последнего релиза из раздела [Releases](https://github.com/Mozzila-ru/PPDF/releases) и распакуйте его в удобную папку (например, `C:\PPDF\`). В архиве уже есть скрипт (`PPDF_vXX.lsp`), а также `pdftk.exe` и `libiconv2.dll`.
2. В AutoCAD введите команду `APPLOAD` (или `_APPLOAD`).
3. Выберите файл скрипта (`PPDF_vXX.lsp`) и нажмите «Загрузить».
4. *(Опционально)* Добавьте папку со скриптом в «Безопасные пути» (Trusted Locations) в настройках AutoCAD, чтобы избежать предупреждений безопасности.

## 🖨 Использование
![Главное окно программы PPDF](images/PPDF_interface.jpg)

![PPDF main window (English)](images/PPDF_interface_EN.jpg)

1. Введите команду **`PPDF`** в командную строку AutoCAD.
2. Настройте параметры в диалоговом окне:
   * Выберите режим печати.
   * Укажите префикс, суффикс и папку для сохранения.
   * Выберите плоттер (рекомендуется `DWG To PDF.pc3`), стиль печати и формат бумаги.
   * Настройте масштаб (пусто или `0` = Вписать).
3. Нажмите **«Отбор и печать»**.
4. Следуйте подсказкам в командной строке для выбора рамок.
5. По завершении печати скрипт предложит объединить файлы в один PDF.

> 💡 **Совет по «Тихой печати»:** если при печати у вас автоматически открывается просмотрщик PDF, нажмите кнопку **«?»** → **«Тихая печать»** в окне PPDF, чтобы узнать, как отключить это поведение в настройках PC3-файла плоттера.

## 📂 Где хранятся настройки?
Настройки хранятся в текстовом файле `ppdf_settings.cfg` в папке:
`%APPDATA%\PPDF\` (обычно `C:\Users\ВашеИмя\AppData\Roaming\PPDF\`).
Там же временно генерируются DCL-файлы диалоговых окон.
